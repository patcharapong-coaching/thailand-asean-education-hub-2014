# การเตรียมความพร้อมการพัฒนาประเทศไทยให้เป็นศูนย์กลางทางการศึกษาการเรียนรู้ในกลุ่มประชาคมอาเซียน

**ผู้เขียน:** พชรพงศ์ พงษ์โพธิ์ไชย (5614480003)  
**วิชา:** HRD 6108 การศึกษาเปรียบเทียบการพัฒนาทรัพยากรมนุษย์ในประชาคมอาเซียน  
**อาจารย์:** ดร.สุมนา จรณะสมบูรณ์  
**สถาบัน:** คณะพัฒนาทรัพยากรมนุษย์ มหาวิทยาลัยรามคำแหง  
**วันที่ส่ง:** 22 มีนาคม 2557 (2014)

เผยแพร่เปิดสาธารณะเพื่อการค้นคว้านโยบายการศึกษา อาเซียน และนโยบายศูนย์กลางทางการศึกษา

## จุดสำคัญ

บทความนี้สรุปบทบาทการศึกษาในการสร้างประชาคมอาเซียน แผน 5 ปีด้านการศึกษาของอาเซียน (2011–2015) นโยบายกระทรวงศึกษาธิการ และวิเคราะห์ SWOT ของระบบการศึกษาไทย

**จุดแข็ง:** ค่าใช้จ่ายที่ประหยัด ทำเลติดพรมแดน สังคมเปิด อาจารย์เป็นกันเอง สังคมยอมรับความแตกต่าง
**จุดอ่อน:** ทุนนักศึกษาต่างชาตน้อย โครงสร้างพื้นฐานไม่พอ ระเบียบราชการไม่เอื้อ นโยบายศูนย์กลางยังไม่ชัดเจน หลากเอกภาพ หลักสูตรใช้จริงในประเทศเพื่อนบ้านได้น้อย
**โอกาส:** ความต้องการเรียนภาษาไทย และสถาบันในประเทศเพื่อนบันไม่พอ
**อุปสรรค:** กำลังทรัพย์นักศึกษาเพื่อนบ้าน ภาษาไทย และความล่าช้าของหน่วยงาน

บทสรุป: ไทยจะเป็นศูนย์กลางทางการศึกษาในภูมิภาคได้ถ้ายกระดันคุณภาพ ภาษา โครงสร้างพื้นฐาน บุคลากร และความเป็นเอกภาพของนโยบาย
